# App de Animais PWA

Projeto web com foco mobile que consome API de gatos e cachorros.

## Funcionalidades
- Busca de imagens por API
- Botão aleatório
- Geolocalização
- PWA instalável
- Funcionamento offline básico

## Tecnologias
- HTML
- CSS
- JavaScript
- Web App Manifest
- Service Worker
